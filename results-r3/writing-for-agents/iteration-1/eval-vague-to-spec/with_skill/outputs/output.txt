Improve dashboard performance and visual design with the following measurable changes:

Performance requirements:
- Reduce initial dashboard load time to under 2 seconds on a standard broadband connection.
- Identify and remove unnecessary API requests during initial page load.
- Lazy-load dashboard sections and data that are not visible on first render.
- Optimize large assets by compressing images, reducing bundle size, and removing unused dependencies.
- Add loading states for any data that cannot be rendered immediately.
- Verify improvements by comparing before/after load metrics using the existing performance monitoring tools.

UI/UX requirements:
- Update the dashboard layout to use consistent spacing, alignment, and component styling.
- Improve visual hierarchy so primary metrics and important actions are immediately noticeable.
- Apply the existing design system components and styles consistently across all dashboard elements.
- Improve readability by adjusting typography, contrast, and data presentation where needed.
- Ensure the dashboard is responsive and usable on desktop and tablet screen sizes.
- Preserve all existing functionality while making the interface cleaner and easier to navigate.

Completion criteria:
- The dashboard meets the target load-time improvement.
- All existing dashboard features continue to work without regressions.
- Updated UI changes are reviewed against the design system and pass accessibility checks.
- Performance and UI changes are documented in the pull request summary.:::
